# Packaging Arrangement Tool / 包装动态排列工具

在线访问：[PocketBay 部署版](https://app-rau1.pocketbay.app/)

## 启动方式

- macOS：优先双击 `启动中包排列工具.app`；也可双击 `打开工具.command`。`.app` 同时支持 Intel 与 Apple Silicon Mac。
- Windows：双击 `start-tool-windows.bat`。系统需安装 Python 3；脚本会依次识别 `py -3`、`python` 和 `python3`。
- Linux：在工具目录运行 `python3 launcher.py`。

启动器会在本机 `127.0.0.1` 创建临时 HTTP 服务并自动打开默认浏览器。请勿直接双击 `index.html`，否则浏览器会以 `file://` 方式打开并阻止三维模块运行。3D 引擎已保存在工具目录中，运行时不依赖外网。网页运行必需的 Three.js、控制器、圆角几何和 jsPDF 已收敛到 `vendor/`，无需在发布环境保留完整 `node_modules`，可直接作为纯静态站点部署。

开发与验证：安装 Node.js 后运行 `npm test`。本地启动不依赖 Node.js，仅依赖 Python 3 和现代浏览器。

当前首版包含：

- 纸手帕、软抽、卫卷三类单粒模型；软抽可切换“普通软抽 / 悬挂式底抽”，悬挂式底抽从包体顶面完整边缘以三角余量收拢至固定高度的柔性双孔薄膜提手，抽取开口与封线位于底面；提手不计入单包高度、排列步距或容器尺寸，装入中包、大包或纸箱时自动折转 90° 贴伏；卫卷可切换有芯与无芯形态；有芯卫卷支持单卷、4卷膜包（2×2×1）、6卷膜包（2×3×1）及自定义 X×Z×Y 组合小包，中包按小包数量排列并同步汇总折合卷数
- 小粒支持自定义 mm 尺寸；箱型产品始终按模型本地的长/高/宽轴缩放，单卷按卷径/卷高轴缩放，再执行平放、侧立或直立姿态，避免自定义尺寸在直装箱时串轴导致模型穿出容器。无芯卫卷另可设置 0–50% 压扁率，并按截面积近似守恒换算椭圆截面的长短轴（例如卷径 100 mm、压扁率 20% → 约 125×80 mm）
- 单粒与中包采用统一结构展示：小粒使用浅色实体或半透明着色保证辨识，中包使用更明显的蓝色透明膜、连续实线轮廓和加强的封口细节，优先读出包装边界
- 纸手帕按实物改为竖向正面、极薄厚度的小袋，带短边横向热封、底部背封、顶面弧形开封线和中央易揭贴（不再显示大面积白色方块）；其中包为无提手的横向长条袋；软抽采用纸叠撑起的方正软包、轻微膜面张力、端部折膜热封和关闭式抽口；卫卷提供独立收缩膜、卷绕层、纸芯或无芯不规则浅凹
- 未锁定具体 SKU 包膜的软抽、卫卷等模型采用“真实维达 Logo + 透明或半透明外膜”，避免使用错误包装文字；Logo 参考来自用户提供的品牌图
- PDF 中主要排列预设，以及自定义行、列、层
- 平放、侧立、立、横、卧等朝向
- 单粒和组合视图、视图爆炸间距、外轮廓、自动旋转；爆炸间距只拉开检查视图，不写入方案快照，也不改变中包、外包装或 PDF 的业务尺寸
- 纸手帕采用无提手中包袋，两端使用贴合袋体的交叉折膜热封，不绘制凸出的端封块；中包外膜 X/Z 端部只保留极薄贴合余量，避免在最外侧小粒与袋面之间形成厚底；软抽、卫卷独立中包视图从包装端面的完整前后边缘开始向柔性提手热封根部整体收拢，侧视形成三角余量区（装入大包/纸箱时不显示且不计间隙），软抽提手为双孔、卫卷为单长槽，对侧固定为折膜热封袋底
- 大包使用柔性 PE 膜质感；袋口边封按真实鳍状热封表达为位于封口面中线、与袋面垂直、覆盖袋口全宽并贴合袋面的连续薄膜片，热封宽度按约 18 mm 表达，不再使用胶条造型
- 透视、正面、侧面、俯视、提手端、袋底端视角；大包/装箱另提供“装入面”视角；透视保留“提手在画面上方”的专用构图，并在每次视角切换时同步控制器旋转基准，避免仅透视图方向反转或拧动；默认“模型跟随鼠标”，也可切换“相机环绕方向”；关闭松手惯性，拖到哪里就停在哪里
- 当前视角 PNG 导出
- 按当前品类或全部品类批量生成 PDF 透视表：左侧名称与排列参数，右侧统一透视图
- 系统预设可编辑保存、另存为自定义预设，并保存在浏览器本地
- 预设 JSON 合并采用“本地优先”：导入文件遇到已存在的内置修改时跳过并明确提示，不静默覆盖本地版本
- 包装层级可切换为中包、大包、装箱；大包/装箱支持当前中包或单粒产品作为装入单元，按外包装 X 行 × Z 列 × Y 层动态组合
- 操作区使用“单粒 → 中包 → 大包 → 装箱”四步建模导航；大包/装箱可明确选择“经中包装入”或“单粒直接装入”，并可一键返回来源步骤修改
- 大包/装箱方案把方向拆成“装入面、摆放姿态、单元朝向”：中包可选平放、侧立、端立，并选择提手或纸手帕长向/顶封面的朝向；切换为单粒直装后，“小粒摆放姿态”会改为该品类的独立选项（纸手帕为平放、侧放；软抽为直立、平放、侧立；卫卷为立、横、卧），并随外包装方案保存
- 装箱工段另按闭箱后的最终长边生成正式名称，格式为“装入规格－相对箱长姿态－X×Z×Y”；箱底 X/Z 相差不超过 3% 时固定以 X 为箱长，避免名称因余量或浮点误差跳变。箱型单元使用“顺/横箱长平放、顺/横箱长侧立、宽边/厚边顺箱长端立”，卫卷使用“立式装箱、卷轴顺/横箱长”。默认词汇集中维护在 `src/carton-naming.js`，单个装箱方案还可填写“正式名称修订”，留空即可恢复系统自动名称
- 软抽单粒直接进入大包/装箱时，“直立（小横截面向下）”排在姿态列表首位，并作为新建/临时直装方案的默认姿态；该姿态只用于外包装直装，不改变软抽中包的平放、侧立定义
- 大包/装箱视图区提供“显示小粒”按钮：展开每个中包袋内的实际单粒模型和当前中包排列；小粒先遵循中包的单粒朝向与开口/裁切面规则，再随中包整体姿态同步旋转
- 中包装入大包或纸箱时，柔性提手按受压状态折转 90° 并贴合中包端面；外包装步距、容器尺寸和参考尺寸均只按中包袋体计算，不预留提手间隙
- 大包封口线和纸箱折盖线会随装入面移动；大包/装箱视图可独立隐藏层级与中包数量标签
- 大包/装箱新建方案默认外包装 Z 列数为 1；关闭箱口时，装入面使用实体纸板箱盖并显示沿长向跨过中缝的一字封胶带，避免顶层产品透过透明箱盖被误读为穿出箱体；打开箱口后箱盖与胶带自动隐藏
- 装箱主视图工具栏提供“打开箱口 / 关闭箱口”切换：打开时按 FEFCO 0201 常规开槽箱结构保留五面箱体，长边摇盖宽度为箱口短边的 1/2，四片摇盖随所选装入面同步换面；开箱状态下另显示“关闭/开启箱体透视”按钮，可在查看内部排列和不透明箱体之间切换
- 装箱方案可选择“无挡板 / 十字挡板”。十字挡板以 4 mm 瓦楞纸板口径在 X、Z 两个实际单元边界相交，并在排列尺寸中自动让出纸板厚度；奇数数量按较少一组在左/前、较多一组在右/后分割（如 5 自动分为 2+3），该要求随方案保存并进入 PDF 业务说明。薄款属性不由工具猜测，是否启用由方案维护人确认
- 外包装方案可按层级保存、另建临时方案或删除，保存在浏览器本地 `vida-outer-presets-v1`；旧方案会自动迁移为对应的平放方向，再继续编辑保存
- 中包在组合视图中按软包装受压效果压薄 Y 向高度（软抽最明显、纸手帕轻度压缩），包装膜余量同步收紧；卫卷保持卷体真实高度，仅收紧包装膜余量；单粒检查视图始终保留产品自身比例
- 默认采用紧密装载口径：中包粒/小包间距为 0%，大包/装箱单元间距为 0，容器余量为 0.05；软抽、卫卷默认透视按参考图固定为“提手位于画面正上方、正面为主、左侧面可见、少量俯视”，并以正斜 45°观察

包装口径已按业务示意图固化：

- 软抽平放：开口刻线向上、宽 100 水平；软抽侧立：宽 100 竖直、开口刻线朝手挽耳；多包观察时手挽耳平放
- 纸手帕：长取小包顶封面方向，宽取小包侧封面方向，高取平放或侧放层数；中包袋无提手
- 卫卷：立为裁切面向上，横为侧面横向入料，卧为裁切面入料；名称中的 `N` 表示摆放行数，列数和层数使用固定数字
- 界面保留 X/Z/Y 作为三维建模轴，同时使用“长向/宽向”“排/每排”“固定列/N 行”等业务名称，避免混淆

说明：模型尺寸为按 PDF 示意关系建立的相对尺寸。若用于设备选型或包装尺寸校核，请补充各类小包/卷纸的实际长、宽、高或直径，后续可切换为毫米级真实尺寸。

外包装可维护大包与装箱自定义方案；临时默认值仅用于验证中包或单粒的排列逻辑，不代表已确认的产线标准。批量 PDF 可按单元定义、中包、大包、装箱及品类筛选，导出期间使用独立互斥会话；关闭、取消或完成后会恢复两个外包装层级的草稿与选择、单元尺寸覆盖、显示模式，以及完整相机和控制器状态。
